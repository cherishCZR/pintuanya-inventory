# 兼容性与限制

本 Alpha 的安装目标为 **Windows 10/11 + CPython 3.12 x64（win-amd64）**。不是“所有 Windows 均保证可用”。

| 环境 | 当前状态 |
|---|---|
| 本地 Windows 11 x64、CPython 3.12 x64 | 已做离线契约、界面、本地代理生命周期与一次普通账号商品响应验证 |
| 全新目录、路径包含中文/空格、Python 位于该副本外 | 独立源包安装、离线测试与空代理启停通过；不是干净系统虚拟机，详见 validation.md |
| Windows 10 x64 消费者系统 | 目标范围，尚无独立干净虚拟机验收 |
| GitHub windows-2022 / windows-2025、Python 3.12 x64 | CI 已配置；当前未上传运行，不能将配置当成通过结果 |
| 32-bit、ARM64 原生解释器、PyPy、其他 Python 版本 | 本安装器不支持 |
| ARM 电脑上的 x64 仿真 | 未验证，不承诺支持 |
| Windows 7/8 或更早系统 | 不支持 |

微信必须能通过标准 HTTP 代理及测试 CA 正常读取本机可访问响应。客户端不走代理、拒绝证书、仅返回不透明内容时，工具只做诊断，不进行注入、Hook、补丁、证书固定绕过或全局关闭 TLS 校验。

只支持当前已观察到的业务结构。没有验证所有团单、全部多规格/分页流程或所有微信版本；访问受限、字段缺失和结构变化都可能限制能力。

默认只做被动采样，依赖用户正常浏览触发请求；主动轮询未实现。stock 的剩余/总量口径尚未确认，默认仅展示原值候选。MIT许可不等于对兼容性或数据准确性的保证。
