# 验证记录

发布整理版本：0.1.0-alpha.1。

## 已有真实观察

曾在单一 Windows 11 x64 环境中，由用户登录普通账号，结合界面角色线索与正常返回的角色标志，观察目标团单的商品 JSON。插件、JSONL、SQLite、本地界面和 CSV 链路已实际运行；没有用模拟或管理端数字回填。

这只能证明该次普通账号正常收到商品与数量候选字段，不能推广到所有团单或所有账号。stock 的剩余/初始总量口径尚未分辨，规范剩余数量留空。原始业务标识、分享链接、凭据、本机路径及完整采样不进入公开源码或发布包。

## 软件验证与真实采样的区别

离线 fixture 用于解析、状态、来源隔离、权限拒绝、存储、恢复、CSV、界面刷新与进程保护测试；它们不是线上采样证明。CI 不登录微信、不发送平台业务请求。

本地代理启动/停止/重启检查使用空环境检查档案，不把系统代理指向它、不请求平台、不生成商品记录；它只证明运行能力。
