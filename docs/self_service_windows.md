# 新团自助采样

安装后双击 start-self-service.cmd，浏览器打开 http://127.0.0.1:8502。不需要 Codex 代填 JSON，也不需要打开 mitmweb 管理页面或寻找管理令牌。

## 首次登记一团

1. 用自己的普通参团账号打开分享入口，自行完成登录和协议提示。确认没有此团的编辑/管理权限，记下完整团名。
2. 展开“① 新建团单”，填团名和链接。代号留空可自动生成，每团有独立的配置、证据、队列、数据库和导出目录。
3. 默认本工具代理端口是8082；上游代理填写你实际使用的 HTTP(S) 代理，没有则留空。不要把上游指回本工具端口。
4. 创建后选择该团，勾选普通账号/入口确认，点击“启动 / 重新开始5分钟观察”。
5. 由你手动把 Windows 测试代理设为页面显示的 127.0.0.1 和端口；标准测试证书按 setup_windows.md 配置。本项目已有 CA 配置可复用，不代表任意旧代理软件的证书都能复用。
6. 在微信从分享入口正常重新进入，等列表、滚动到底、打开商品和规格。只正常查看，不加数量试探、不加购物车、不下单或支付。不要切管理账号。
7. 返回页面点“读取观察结果（仅本地）”。核对实际团名、商品和规格。同名多团时必须选中实际对应的团单；不会把分享短码直接当成团单 ID。
8. 普通角色和商品结构检查通过后，勾选对应关系确认，点“确认绑定并启用此团被动采集”。已观察的最小商品片段入库，随后仅提取此团的白名单商品响应。

观察超过5分钟可重新开始；旧证据保留、新窗口单独登记。没有真实响应、权限不符或结构不支持时不能确认绑定，也不会生成“成功库存”。

## 日常使用

1. 选择已登记团单，点“启动此团被动采集”，让测试代理指向页面显示端口。
2. 在微信普通账号中正常重新进入、浏览或刷新。
3. 回页面点“同步本地记录并生成 CSV”。这只消费本地队列，不向平台发起库存查询。
4. 查看表格，下载原始候选 CSV 或规范库存 CSV。原始候选未确认时，规范剩余数量为空。

一次在同一代理端口采一团。换团前先停止旧团再启动新团，或为新团选独立空闲端口。端口被其他程序占用时软件报错，不结束未知程序。界面刷新本身不会采集；只有微信真实产生新响应时才有新观察。

## 如何读结果

- stock/sale 是实际响应中的原始字段候选，不自动解释为剩余/总量/销量。
- 缺字段、null、未确认、错误和0分别记录；不会把未知转成0。
- 只对语义已确认的相同库存口径计算库存变化，不把差值称作销量。默认自助适配器不确认数量语义，也不做 stock-sale 运算。
- 覆盖默认 partial/unknown。滚到底或 next=false 只说明本次筛选范围，不能证明包含隐藏/下架商品和全部规格。
- 显示本地观察时间、过期/失败提示；缺少业务服务端时间时不保证实时。

## 没有结果时

先核对完整名称、代理端口、标准证书和观察时限，并正常重新进入。访问被拒绝/未登录不等于没有库存；只有 CONNECT/TLS 错误说明正文不可读；结构不支持说明当前适配器无法解析。

普通角色未确认时保持普通账号并重新观察。不能通过清除管理员字段伪造角色，不能用管理端数据补普通账号结果。

结束时先手动恢复测试前的系统代理，再停止本团服务。测试 CA 不再需要时由你手动移除本次证书。不要分享 secrets、原始 HAR 或登录凭据。
